# Data Visualisation

Interactive data visualisation projects using Python and Jupyter Notebooks.

## Overview

Exploring effective ways to communicate data insights through visualizations:

- **Exploratory Analysis**: Understanding datasets through visual patterns
- **Statistical Plots**: Distribution, correlation, and trend analysis
- **Interactive Dashboards**: Building dynamic visual representations
- **Geospatial Mapping**: Location-based data visualization

## Tools & Libraries

- Python
- Jupyter Notebooks
- Matplotlib, Seaborn
- Plotly, Bokeh
- Pandas, NumPy
- Folium (geospatial)

## Project Structure

```
├── notebooks/       # Jupyter notebooks
├── data/            # Datasets
└── outputs/         # Generated visualizations
```

## Getting Started

```bash
git clone https://github.com/panchalaman/datavisualisation.git
cd datavisualisation
pip install -r requirements.txt
jupyter notebook
```
